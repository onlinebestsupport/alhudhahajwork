## 🌐 URL / Route Structure

Flet runs as a **single-page app** — no URL routing by default. Everything happens in one URL.

```
http://127.0.0.1:5000/          ← Everything lives here
```

**But internally, these "views" replace the page**:

| View | How it's shown | How to exit |
|---|---|---|
| Login | `page.controls.clear()` + `page.add(login_view.build())` | On success → Main Window |
| Main Window | `page.controls.clear()` + `page.add(main_window.build())` | Logout → Login |
| Custom Report | Saves `page.controls`, clears, adds full-page | **✕ Close** or **← Back** |
| Traveler Full Report | Same as above | **← Back** |
| Reorder Columns | Dialog (overlays current page) | **Cancel** / **Apply** |
| All Add/Edit dialogs | `ft.AlertDialog` overlay | **Cancel** / **Save** |
| Confirm Deletes | `ft.AlertDialog` overlay | **Cancel** / **Delete** |
| Snackbar messages | `ft.SnackBar` (auto-dismiss) | auto or swipe |

## 🎯 User Journey Examples

### Journey 1: Add a new traveler
```
Login → Dashboard
   └─ Quick Action "➕ Add Traveler"
        └─ TravelerDialog opens (overlay)
             └─ Fill form → Save
                  └─ Snackbar "✅ Traveler added"
                       └─ Dialog closes → Dashboard refreshes
```

### Journey 2: Create a custom report
```
Login → Reports tab
   └─ Custom Reports sub-tab
        └─ [🚀 Open Custom Report]
             └─ Full-page view opens (hides main window)
                  ├─ Select columns
                  ├─ [🔄 Generate Preview]
                  ├─ [📌 Reorder Columns] → dialog → apply
                  ├─ [📊 Excel] → browser download
                  └─ [✕ Close] → returns to Reports tab
```

### Journey 3: View a traveler's photo
```
Login → Reports tab
   └─ Single Traveler sub-tab
        ├─ Select traveler from dropdown
        ├─ [📥 Load Selected]
        │    └─ Photo + summary + documents appear
        └─ [👁️ View Full Report]
             └─ Full-page report (hides main window)
                  └─ [← Back] → returns to Reports tab
```

### Journey 4: Restore a backup
```
Login → Backup tab
   └─ Click ⋮ on a backup row
        └─ 🔄 Restore This Backup
             └─ Confirm dialog
                  ├─ Yes → safety backup created → restore → snackbar
                  └─ No → cancel
```

### Journey 5: Change company logo
```
Login → Settings menu (⚙️ top-right)
   └─ Company
        └─ CompanySettingsDialog opens
             ├─ Upload Logo → FilePicker → base64 preview
             ├─ Fill fields
             └─ [💾 Save All Settings]
                  └─ Snackbar "✅ Settings saved"
                       └─ Dialog closes
```

## 🔑 Key Navigation Patterns

| Pattern | Purpose | Implementation |
|---|---|---|
| **Tab switch** | Move between major sections | `tabs.selected_index = N` |
| **Sub-tab switch** | Move within Reports | `reports_tabs.selected_index = N` |
| **Full-page navigation** | Custom Report, Full Report | Save `page.controls`, clear, add new |
| **Full-page return** | Back button | Restore saved `page.controls` |
| **Modal dialog** | All forms (Add/Edit/Settings) | `page.show_dialog(ft.AlertDialog(...))` |
| **Popup menu** | ⋮ actions in tables | `ft.PopupMenuButton(items=[...])` |
| **Snackbar** | Success/error messages | `page.show_dialog(ft.SnackBar(...))` |
| **File download** | Exports | `await file_picker.save_file(src_bytes=...)` |
| **File upload** | Logo, Import backup | `await file_picker.pick_files(with_data=True)` |
